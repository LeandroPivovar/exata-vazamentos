# Exata Vazamento e Desentupimento - site institucional

Site one-page da **Exata**, caça vazamento e desentupimento com atendimento 24 horas.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, galeria, depoimentos, mapa, FAQ)
styles.css   # estilos (azul-marinho e vermelho do mascote, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Mapa:** o `iframe` mostra a ficha da empresa no Google Maps (busca "Exata soluções hidráulicas, Londrina - PR", zoom 10). A ficha não tem endereço público, então o mapa exibe a área de atendimento cadastrada (Londrina e região) e o cartão com a nota. O botão "Ver no Google Maps" abre a ficha com as avaliações.
- **Depoimentos** são exemplos. Substitua por avaliações reais de clientes.
- **Logo**: `assets/logo-exata.png` é o logo oficial (mascote, "Exata Soluções Hidráulicas"), reduzido para 400px. O original está em `assets/_originais/` (fora do git).
- **Galeria**: fotos reais de atendimentos em `assets/galeria/`, com filtros Caça vazamento, Desentupimento e Caixa d'água.
- Contato: WhatsApp/telefone `+55 43 8872-1190` (`wa.me/554388721190`). Confira se o número está completo.
- Existe uma página no Facebook ("EXATA CAÇA VAZAMENTO"); o link pode ser adicionado no rodapé.
